# FVCC Cricket — Android starter

This is a Flutter starter project for the Fortview Cricket Club app. It includes the original supplied club logo and a blue-and-white dashboard prototype.

## Important
This is **not an installable APK** and is not a finished app. Login, admin/scorer approval, persistent player/team data, ball-by-ball scoring, tournament calculations, cloud backup and offline sync still need implementation and testing.

## Build locally
1. Install Flutter SDK and Android Studio.
2. From this folder run `flutter pub get`.
3. Connect an Android phone or start an emulator.
4. Run `flutter run`.
5. To create an APK after implementation/testing, run `flutter build apk`.

The current screen is a navigation prototype only.
